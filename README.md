# 🧠 우울증 환자 액티그래프(Actigraph) 시계열 데이터 분석 및 머신러닝 예측

본 프로젝트는 손목 착용형 액티그래프(Actigraph) 센서로 수집된 24시간 연속 신체 활동량(Motor Activity) 시계열 데이터를 분석하여 우울증 환자의 객관적인 **디지털 바이오마커(Digital Biomarker)**를 도출하고, 머신러닝을 통해 우울증 여부를 분류/예측한 연구 발표 프로젝트입니다.

## 📊 핵심 연구 결과 요약
1. **아침 기상 구간(06:00~10:00)의 현저한 활동성 저하**:
   - 건강 대조군(193.0) 대비 우울증 환자군(102.4)의 아침 평균 활동량이 **약 47% 감소** ($p = 0.0015$, Cohen's $d = -0.94$).
   - 기상 지체 및 아침 무기력증(정신운동 지체)이 객관적 센서 수치로 명확히 검증됨.
2. **질환 중증도(입원 환자 vs 외래 환자)와의 일치성**:
   - 급성/중증 입원 환자는 하루의 **55%**를 무활동 상태로 보내며 외래 환자보다 더 심각한 신체 활동 위축을 보임.
3. **머신러닝 기반 자동 분류 실효성**:
   - 5-Fold Stratified CV에서 Logistic Regression 및 Gradient Boosting 모델이 **약 71% 정확도와 0.73 AUC** 달성.
   - 1,035일 일별 데이터 대상 GroupKFold(환자 분리 검증)에서 Random Forest 모델이 **70.8% 정확도, 0.756 ROC-AUC** 기록.
